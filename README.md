# 📈 Stock Price Prediction Using Transformers

A portfolio-ready machine learning project that uses **Transformer architectures** to forecast stock prices from historical data.  
The goal is to build a strong ✨ *resume-worthy* pipeline for time-series forecasting using deep learning.

## 📁 Repository Structure

```text
StockPrice/
├── data/                         # CSV datasets like AAPL.csv, TSLA.csv
├── models/
│   └── transformer_model.py      # Transformer architecture
├── utils/
│   ├── data_utils.py             # Dataset loading & preprocessing
│   └── metrics.py                # Evaluation metrics (MAE, RMSE)
├── results/
│   └── plots/                    # Model and prediction plots
├── train.py                      # Train the model
├── predict.py                    # Run predictions
